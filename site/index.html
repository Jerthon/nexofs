Recursos

Feito para quem confia dados de verdade à nuvem

Cada decisão de design prioriza previsibilidade: nada é baixado sem pedir, nada é sobrescrito sem avisar.

Multi-provedor

OneDrive e Google Drive hoje, com o núcleo pronto para novos provedores via uma trait única (CloudProvider).

Indexação preguiçosa

Nada é listado ou baixado até você navegar até lá — sem varredura inicial em nuvens gigantes.

Fixação seletiva

Marque qualquer arquivo ou pasta para ficar sempre disponível offline; o resto permanece só-na-nuvem até ser aberto.

Cache de conteúdo local

Contabilização por conta — limpo, modificado, parcial ou mantido localmente — sempre visível.

Exclusões estilo .gitignore

Perfis sugeridos automaticamente a partir de manifestos do projeto (package.json, Cargo.toml, etc).

Conflitos nunca-silenciosos

Nenhuma escrita concorrente é descartada sem você decidir explicitamente o que fazer.

Interface desktop

App em Tauri com abas para contas, arquivos, exclusões, operações, conflitos, cache e log de sync em tempo real.

CLI de administração

nexofs cobre tudo que a interface gráfica faz — ideal para servidores e automação.

Daemon separado da UI

nexofsd continua sincronizando mesmo com a janela fechada.

Arquitetura

Núcleo agnóstico de nuvem

O nexofs-sync-core não conhece OneDrive nem Google Drive — fala apenas com a trait CloudProvider.

Todo tráfego externo passa por um governor central de taxa/circuit-breaker (nexofs-api-governor); o índice local vive em SQLite com WAL (nexofs-metadata-store). Decisões documentadas em docs/adr/.

Princípios de design

Cada trade-off é documentado

As decisões arquiteturais do NexoFS vivem em Architecture Decision Records — com o porquê de cada escolha.

ADR-005

Daemon separado da UI

A sincronização não depende da janela estar aberta — o daemon é o dono do estado.

ADR-006

Núcleo agnóstico de provedor

Novo provedor de nuvem = nova implementação de CloudProvider, sem tocar no core.

ADR-008

Indexação preguiçosa por padrão

Montar uma conta não dispara varredura completa — só o que você abre é indexado.

ADR-012

Conflitos nunca sobrescrevem em silêncio

Escrita concorrente vira conflito explícito, nunca perda de dados invisível.

Instalação

Pacote pronto ou a partir do código-fonte

Instaladores .deb e .rpm com tudo num único pacote — daemon, CLI e interface gráfica —, organizados por versão.

Baixar .deb (v0.1.1) Baixar .rpm (v0.1.1)
Todas as versões · Notas de release no GitHub 
# .deb/.rpm com daemon + CLI + interface gráfica no mesmo pacote —
# receitas em packaging/deb (debian/rules) e packaging/rpm (nexofs.spec)
sudo apt install ./nexofs_<versão>_amd64.deb
sudo dnf install ./nexofs-<versão>.x86_64.rpm
# compilar sem empacotar — útil pra desenvolver
cargo build --release -p nexofsd -p nexofs-cli

cd desktop
npm install
cargo tauri dev
# credenciais do app, não do usuário — ver ADR-015
export NEXOFS_GOOGLEDRIVE_CLIENT_ID="..."
export NEXOFS_GOOGLEDRIVE_CLIENT_SECRET="..."
cargo build --release -p nexofsd
